# Current security boundaries

Guest ownership is derived from a 256-bit server-issued HttpOnly SameSite=Strict cookie, hashed for database queries. No legacy identity or data is merged. Guest sessions are device scoped, not verified multiuser accounts. Publishing and sharing remain disabled.

POST requires matching Origin (MYSPACE_HOST_ORIGIN if configured, otherwise request origin), JSON content type, an existing guest cookie, bounded streaming input (18 KB), strict operation fields and a known built-in app. Source, ownership and publication fields are rejected. Notes storage is limited to 16 KB UTF-8. The installation must exist; storage writes require storageGranted=true. Overview masks data when permission is absent. Revocation preserves stored data but closes the UI runtime and denies reads/writes. Uninstall deletes installation and data.

The current built-in Notes iframe has sandbox=allow-scripts without allow-same-origin and CSP default-src none, connect-src none, form-action none. Messages check exact iframe window and a per-instance nonce. No general-purpose token or cookie enters the iframe. This minimal bridge is not yet the versioned production SDK and lacks correlated save acknowledgements and robust cancellation.

A MongoDB-backed fixed-window limiter permits 120 protected requests/minute per guest across backend processes. TTL cleanup removes expired buckets. Fresh guest identities can still bypass per-identity limits; edge IP/abuse controls remain necessary. Full platform isolation, resource exhaustion, malicious app and browser end-to-end tests remain outstanding. Generated-code builds are disabled. SSH credentials, external network proxying and arbitrary packages are unsupported.

## Native host integration

The native Myspace WKWebView uses persistent website data. Its only native handler accepts bounded arrays of pinned built-in app IDs/names, gated on HTTPS api.sycord.site main-frame origin. It has no credential, filesystem, command or notification operation. The bridge is not injected into child frames. Main navigation is constrained to the trusted Myspace page, while opaque iframe about:srcdoc navigation remains allowed. Native pin metadata is a cache of the web installation state, not authorization. Actual launches still use web server ownership checks. These boundaries compile but have not been exercised in iOS WebKit.

Project endpoints reuse the same guest cookie hash and canonical-origin CSRF check, and require an existing guest session. Every read/write includes owner. Zod strict schemas reject ownership/publication fields and unsafe file paths. Request bodies are read with streaming size bounds. UUID project IDs are validated before queries. Source snapshots are never imported into the host, executed, or installed. Source versions have separate draft and working pointers; current implementation never sets workingVersion. Database/API integration checks for these new endpoints are still pending.

## Approved public HTTP gateway

API Inspector's network operation is scoped to that installation and separately default-denied by networkGranted. Root installation consent grants storage only; approved network access must be enabled in trusted host app settings. Each request checks server-derived owner, existing installation and current network grant, plus 20 network requests/minute and the shared guest limiter.

The gateway permits exact configured HTTPS domains (MYSPACE_NETWORK_DOMAINS; default api.github.com), port 443, no URL credentials/fragments/IP literals, and only Accept/Content-Type input headers. Cookie, authorization, host and proxy credentials are not forwarded. It resolves all DNS results and rejects any non-public range using ipaddr.js; the chosen public address is pinned to the TLS request lookup, with the approved hostname retained for TLS. Redirects are revalidated (maximum three), and write-method redirects are rejected. Request data is bounded, responses are capped at 256 KB, compressed responses are rejected, and DNS/overall deadlines apply. Only Content-Type response metadata crosses the bridge, not Set-Cookie.

Network grant revocation denies subsequent requests; requests already sent cannot be recalled. No secrets should be put in Inspector presets; its header editor deliberately does not support credentials. The current gateway is not an SSH or arbitrary internet proxy. Injected-resolver tests for rebinding/redirect corner cases, resource-exhaustion tests and full egress threat validation remain outstanding. A host frame-src policy now restricts frames to self/blob/data, preserving sandboxed library previews. Chromium checks deny external HTTPS frame navigation, direct fetch, popup creation and parent DOM access. More exhaustive escape/egress tests remain required before generated or third-party code is enabled.

Network audit records now capture owner hash, app ID, operation, approved domain, method and outcome (plus response status/duration on completion). They never retain URL path/query, headers, request/response bodies or credentials. Permission denials are recorded. Records expire after 90 days using a MongoDB TTL index. Audit initialization or start-record failure prevents a new network request; a failure updating the final record may report an error after the external request has already completed. This is not exactly-once external execution.
