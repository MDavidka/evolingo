## Color Tokens
- `background.primary`: `#FFFFFF`
- `text.primary`: `#202127`
- `text.strong`: `#111111`
- `text.secondary`: `#8E8E93`
- `text.tertiary`: `#AEAEB2`
- `surface.subtle`: `#F5F5F7`
- `surface.secondary`: `#FAFAFA`
- `border.subtle`: `#E5E5EA`
- `action.primary`: `#1C1C1E` / `#202127`

## Typography & Layout Principles
- **Display / Standalone Large Number:** `38pt` bold tabular numerals (`#111111`)
- **Primary Result Value:** `26pt` bold (`#111111`)
- **Major Heading:** `22pt` bold (`#202127`)
- **Icon + Heading (`REF-02`):** `19pt` bold (`#111111`) with leading `21pt` Tabler icon
- **Assistant Body:** `16pt` regular (`lineSpacing: 6.5pt`)
- **File Row Title (`REF-01`):** `16.5pt` semibold (`#202127`), backgroundless with `1pt` `#F2F2F6` separator
- **Timeline Step (`REF-02`):** `16pt` semibold title, `13.5pt` `#6E6E73` subtitle, `1pt` `#D1D1D6` vertical connector, restrained status pills (`#E3F5E8` / `#247A3D` for Complete)
- **Inline Map Preview (`REF-04`):** `196pt` height, `20pt` continuous corner radius, backgroundless
